## Codebase Patterns

### Project Structure
- TypeScript project using Node 22 (ES2022 target, NodeNext modules)
- Source files in `src/`, compiled output in `dist/`
- Tests in `src/__tests__/*.test.ts` using Vitest
- Dependencies: axios (HTTP client), vitest (testing), typescript

### Conventions
- Import with `.js` extension for NodeNext compatibility
- Use strict TypeScript settings
- RSA private key at `kalshi_key.pem` for API auth
- Auth utilities in `src/auth.ts`:
  - loadPrivateKey() for key loading/validation
  - signRequest() for V2 API request signing
  - createStringToSign() for request string construction
- Authentication: signRequest(method, path, privateKey, keyId, body?) returns KalshiAuthHeaders
- String-to-sign format: timestamp + METHOD.toUpperCase() + path + body
- Testing: Use vi.useFakeTimers() + vi.setSystemTime() for deterministic timestamps
