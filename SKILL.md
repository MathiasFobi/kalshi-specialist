# Kalshi Trading Specialist

Use this skill to interact with the Kalshi Exchange API (V2).

## Tools

- `kalshi_get_market`: Look up market details by ticker.
- `kalshi_execute_order`: Place a buy/sell order.
- `kalshi_get_balance`: Check account balance.

## Configuration

- `KALSHI_KEY_PATH`: Path to the RSA private key file.
- `KALSHI_API_BASE`: https://demo-api.kalshi.com (Demo) or https://api.kalshi.com (Prod)
